
## 2026-10-22 圆环入口与主菜单

启动直接进入黑底圆环。图像 `assets/ring.png` 与 `assets/menu.png` 分别直接复制自用户提供的圆环图与雪山主菜单图，未经过重新生成。圆环中央文案按本次要求为 `The Fifith Season`，主菜单为 `THE FIFTH SEASON`。

- 点击右下角摄像头图标并授权：食指尖出现发光光标。沿圆环顺时针移动一整圈进入主菜单；逆时针会回退进度，丢失跟踪不会凭空增加角度。
- 食指悬停选项：文字放大并发光。双手各自将拇指和食指捏合，稳定保持约 0.3 秒确认。松开后才允许下一次确认。
- `New game`：开始新的序章；`continue`：读取当前浏览器本地存档，无存档时不可选；`exist game`：返回圆环并关闭摄像头。
- 鼠标：按住圆环附近顺时针拖动一圈，进入后悬停并点击菜单。
- 键盘：入口按 Enter 进入菜单，菜单上下键选择并 Enter 确认；游戏内按 Escape 返回菜单。
- 摄像头模型首次开启需要联网下载，视频在本机处理。手势控制不影响鼠标、触屏及键盘使用。

检查：`node tests/check-interaction.mjs` 验证整圈解锁、逆时针、跳点、跟踪恢复和双手捏合去重；`node tests/check-level.mjs` 验证原有十枚余烬仍可收集。
