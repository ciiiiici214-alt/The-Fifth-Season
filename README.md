# The Fifth Season

黑白风雪中的 2D 手势冒险。独立 HTML / CSS / JavaScript，使用项目已有的 Palmetto 字体。画面以 Canvas 程序绘制，参考提供的故事板氛围，不包含故事板上的文字或边框。

## 本地运行

安装 Node.js 后在 VS Code 打开本目录，终端运行 `node server.mjs`，访问 http://127.0.0.1:5173 。不要直接双击 HTML：摄像头需要 localhost 或 HTTPS。

## 操作

- 加载页：旅人与猫随加载进度沿细线行走。
- 风雪序章：文字依次出现；开启摄像头后，张开手掌向右扫，或点击继续。
- 教学：右扫或点击开始旅程。
- 手掌左右位置控制行走；中间 38%～62% 停止；单独伸出食指向上跳跃。
- 键盘 A/D 或左右方向键移动，W/上方向键/空格跳跃；触屏使用方向按钮。
- 收集 10 枚余烬并进入右端古树光门；落水回到上一处岸边并保留余烬。
- 摄像头视频只在本机处理；手势依赖首次联网加载 MediaPipe 模型。关闭摄像头会立即停止视频轨道。

## Cloudflare

运行 `node build.mjs`、`npm install`、`npx wrangler login`，再运行 `npm run deploy`。
也可在 Cloudflare Pages 连接本 GitHub 仓库，构建命令 `node build.mjs`，输出目录 `dist`。

## 设计与限制

本版为完整可玩的单季原型：序章、教学、三段森林区域、收集与结尾。场景为程序绘制，并非附件中的原画文件。手势识别需要摄像头授权与实际光照；键盘和触屏不依赖模型。字体的发布授权由字体持有者确认。
