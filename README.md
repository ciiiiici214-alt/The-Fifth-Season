# The Fifth Season

HTML、CSS、JavaScript 分开保存。所有可见文字使用用户提供的 Palmetto 字体，故事和教学文字按参考图保留。

## 打开

双击 `index.html` 即可运行核心游戏，无须安装依赖、联网或构建。请保持 assets、font.css、style.css、level.js、game.js 和 index.html 在同一项目目录中。

推荐在 VS Code 终端运行 `node server.mjs`，浏览器访问 http://127.0.0.1:5173/ 。摄像头手势首次开启需要联网加载模型，并允许摄像头权限；键盘不依赖模型。

## 操作

加载结束自动显示标题与序章。点击画面、右下角箭头，或按 Enter / 右方向键前进至教学、收集目标及关卡。

- 左右方向键 / A D：行走。
- 上方向键 / W / 空格：跳跃。
- 摄像头图标：开启或关闭手势。张开手掌左右移动控制行走，回中心停止，单独向上伸食指跳跃；右扫进入下一页。
- 收集十枚余烬后继续向右到达终点。高处余烬需跳跃；雪岸连续，不存在未绘出的平台间隙。可向左返回补收。

## 字体和背景

`font.css` 内嵌原始 OTF 的完全相同字节，避免直接打开文件时的跨域字体限制。`node build.mjs` 会从原始字体重新生成该文件，并将完整静态游戏复制到 dist。

`assets/forest.png`、`assets/winter.png` 使用内置 imagegen 根据用户参考图清理生成；森林去除背景中的文字、静态人物和发光道具，冬景去除静态文字，游戏文字与角色分别渲染。

本次只修改本地项目，未执行 Cloudflare 发布。

## 验证

`node tests/check-level.mjs` 使用与浏览器相同的物理逻辑，验证全部十枚余烬的可达性、连续地面、停止和跳跃行为。

本地网页已验证字体加载、加载到序章、行走和跳跃收集。浏览器自动化不允许 file://，因此直接双击流程的实机浏览器验证仍需在用户浏览器中完成；核心脚本已去除 ES module，字体已内嵌。
